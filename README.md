# Medical Equipment Management System

## Overview
This project demonstrates SQL fundamentals by designing and managing a Medical Equipment Management System database. It includes equipment inventory, maintenance records, departments, and SQL query practice.

## Objectives
- Design a relational database
- Store equipment information
- Track maintenance records
- Practice SQL queries
- Understand database relationships

## Technologies Used
- SQL
- MySQL

## Files
- schema.sql
- insert_data.sql
- basic_queries.sql
- joins.sql
- aggregate_functions.sql
- advanced_queries.sql
